# To-Do-List-Using-React-
This Repo contain Customtkinter, tkinter and mysql.connector libraries.

#Customtkinter

Customtkinter is used for custom gui and custom font used in gui making.  

#Tkinter

tkinter is used to create an interface for users to interact with (basically GUI). Helps in much clear input-output interface.

#mysql.connector

Makes a local database on your computer to access the to-do list tasks. Obviously To-do list need local database not and online database (if you want other people to see your tasks, etcs).

This is my first project that I've done. It contain object orientated programming (OOP) which helps in ease to access for the fuction call anywhere.
